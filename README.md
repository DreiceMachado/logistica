# Sistema de Logística

Trabalho da disciplina Fundamentos de Programação para Internet - UNIPAR EAD.

Sistema em PHP para cadastrar produtos, endereços e transportadores e gerar fretes, onde um transportador pode levar vários produtos. Também dá pra baixar um relatório dos fretes de um dia.

Feito com PHP, MySQL, HTML, CSS, JavaScript e Bootstrap.

## Como rodar

1. Iniciar o Apache e o MySQL no XAMPP
2. Colocar a pasta em `C:\xampp\htdocs\logistica`
3. Importar o arquivo `banco/banco.sql` no phpMyAdmin
4. Acessar `http://localhost/logistica`
